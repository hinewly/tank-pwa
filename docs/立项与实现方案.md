# 坦克对战：钢铁代差 · 首版立项与实现方案

- 日期：2026-11-27
- 状态：第一人称十面合围首版实现完成，正式部署待确认
- 产品全名：坦克对战：钢铁代差
- 短名：坦克对战
- App ID：`tank`
- 最终路径：`https://daobox.net.cn/tank/`

## 一、产品目标

把「坦克对战：钢铁代差」做成 DaoBox 正式娱乐子程序。首版不是俯视坦克、战棋或移动敌人关卡，而是 **99A 第一人称炮塔视角的十面合围**：

- 玩家位于战场中心，以炮塔/车长位置观察世界。
- 10 座虎式固定炮台全部在开局同时存在。
- 敌方车体不移动、不转向，只允许炮塔 360° 限速跟踪和独立开火。
- 玩家必须在被摧毁前清空全部 10 座炮台。
- DaoBox 账号、共享时长、儿童模式、打卡、云同步、PWA、离线与反馈全部保留。

## 二、核心玩法

### 2.1 第一人称视角

- 相机固定在 99A 炮塔位置。
- 横向 yaw 可连续 360° 旋转；纵向 pitch 仅用于自然观察，限制在约 ±0.2 rad，不产生翻滚。
- 世界仍是二维逻辑坐标；渲染使用自研 2.5D 透视投影，按相对方位、距离、地平线和物体高度投影到 Canvas 2D。
- 不显示完整俯视地图，不使用俯视跟随相机。
- HUD 显示车体/炮塔独立航向、相对角、中央准星和 360° 威胁罗盘。

### 2.2 十面合围

- 北队 5 座：西翼、西北、正北、东北、东翼。
- 南队 5 座：西翼、西南、正南、东南、东翼。
- 全部敌车在 `resetBattle()` 时一次生成，单局没有补兵、波次、逐个解锁或轮流激活。
- 玩家出生在 `(1100, 750)` 战场中心。
- 敌车车体 `x/y/angle` 生成后永久固定。

### 2.3 固定炮台

- 每座敌车独立维护炮塔角、弹匣、装填和射击冷却。
- 初始装填按阵位轻微错开，避免十座炮台同一毫秒齐射。
- 炮塔持续朝玩家方向限速旋转。
- 玩家在射程内且炮塔误差足够小时即可开火；不额外检查“是否能看见玩家”。
- 炮弹发射后沿真实 2D 世界弹道运动，先撞到哪种实体，就由哪种实体吸收或受伤。

### 2.4 装甲与伤害

装甲按弹着方向与车体朝向的夹角判定：

- 正面：伤害 ×0.65，并有小概率跳弹。
- 侧面：伤害 ×1.00。
- 后部：伤害 ×1.45。

玩家车体朝向和炮塔朝向独立。HUD 必须持续展示两者相对方向，玩家需要用履带转向把正面装甲对准威胁。

### 2.5 掩体

- 混凝土：不可摧毁，形成长期安全角。
- 木障：可摧毁，为玩家提供短时挡炮并打开新机动路线。
- 沙袋：中血量，可被持续火力打穿。
- 敌车：同阵营炮弹会被车体挡住，不造成友军伤害。
- 残骸：坦克被击毁后生成，继续阻挡移动和炮线，成为动态掩体。

地图围绕中心设置内圈立柱、四个方向硬掩体、中圈沙袋和外圈木障，刻意保留多条机动路线和少量起始安全角。

## 三、输入

### PC

- `W/S`：沿车体朝向前进、倒车。
- `A/D`：车体转向。
- 鼠标：锁定后控制炮塔 yaw 和轻微 pitch。
- 鼠标左键 / `Space`：开火。
- `R`：手动装填。
- `Esc`：暂停并释放鼠标。

### 手机

- 左摇杆：纵向油门、横向车体转向。
- 右摇杆：连续环视与炮塔瞄准。
- 独立开火键：按住连续射击。
- 双指可同时驾驶和环视。

## 四、技术实现

```text
public/
├── index.html
├── style.css
├── data.js          # 10 个阵位、障碍、炮台和装甲参数
├── sync.js          # app=tank 云同步
├── game.js          # 第一人称投影、移动、炮台、弹道与渲染
├── service-worker.js
├── manifest.json
└── icons/
```

### 4.1 投影

- 以玩家世界坐标和炮塔 yaw 为相机。
- 对每个世界对象计算相对方位、前向深度和屏幕横坐标。
- 地面基准线由地平线、眼高和距离决定。
- 物体尺寸随 `FOCAL / depth` 缩放。
- 视野外目标不绘制。
- 敌车、障碍、弹道、爆炸、命中文字和残骸全部通过同一套投影。

### 4.2 第一人称取舍

首版使用 **2.5D 全景投影 + 矢量 billboard**，不引入 Three.js、WebGL 框架或外部美术。它满足：

- 连续 360° 环视；
- 近距离目标变大、远距离目标缩小；
- 世界移动会改变投影位置和深度；
- 固定炮台和掩体能按前后关系遮挡；
- 纯 Canvas 2D、零构建、静态部署。

未采用真实三维网格、地形高度、炮镜光学畸变和复杂材质；这些留待后续版本评估。

前期开源调研仍用于车辆、碰撞和炮塔表现参考：

- `niccolofanton/tanks-game`：动量车体、旋转矩形碰撞与手写 2D 数学。
- `vimaltiwari2612/classic-tank-1985`：可破坏/不可破坏掩体和基础射击目标。
- `quarkdev/battletanks`：车体/炮塔分离与爆炸反馈。

第一人称投影、坐标变换、2.5D billboard 和弹道遮挡均为本项目自行实现，未复制外部源码。

### 4.3 弹道

- 炮弹记录上一帧和当前帧世界坐标。
- 使用线段与矩形/圆形相交，防止高速穿模。
- 障碍和坦克中选择最近碰撞点。
- 同阵营坦克只阻挡炮弹，不互相扣血，避免合围阵位自我消耗。
- 最后一辆敌车被击毁后清除在途敌弹，避免胜利结算竞态。

## 五、DaoBox 平台能力

| 能力 | 接入方式 |
|---|---|
| 游客身份 | portal Cookie + 浏览器本机存档 |
| 注册 / 登录 | `DB_HOME` 登录页，`src=tank` |
| 共享时长 | portal `/api/time` 与 `daobox:timeexceeded` |
| 会员不限时 | 由 portal 返回 `unlimited` |
| 儿童游戏池 | App ID 非学习类，由 worker 自动归入游戏池 |
| 账号胶囊 | `#db-account-slot` + `PILL_ANCHORS.tank` |
| 打卡 | `CHECKIN_APPS.tank` |
| 反馈 | portal 自动注入 |
| 云同步 | `/api/backup?app=tank`，本机合并、防空覆盖、离线补传 |

portal.js 异步加载，跨域不可用时不能阻塞第一人称游戏启动。

## 六、PWA

- `manifest.scope = "./"`，部署到 `/tank/` 后默认 scope 为 `/tank/`。
- 缓存前缀固定 `dbtank-`。
- activate 只删除 `dbtank-*` 旧缓存。
- 导航网络优先，离线回退缓存。
- 当前版本：`v0.2.0`，SW `dbtank-static-v4`，资源 `?v=4`。

## 七、自动验收

- `node --check` 覆盖全部 JS。
- 开局敌车数量严格为 10。
- 8 秒以上持续战斗后数量仍为 10，ID 集合不变。
- 每辆敌车 `x/y/angle` 漂移必须为 0。
- 至少多座敌车炮塔转动并独立开火。
- 360° 环视测试必须覆盖 10 个敌车 ID。
- 玩家移动后目标投影深度减小、缩放增大，屏幕横向位置仍正确。
- 玩家瞄准并实际发射炮弹可让环形目标扣血。
- PC 鼠标锁定、环视、开火、暂停和胜负通过。
- 手机左摇杆驾驶、右摇杆环视、独立开火键和双指操作通过。
- 云同步、共享时长锁定、portal 中断、离线和 PWA 缓存隔离通过。

## 八、部署边界

本阶段不部署 tank 站点，不改 Caddy、DNS 或首页入口。代码提交与推送完成后，等待用户验收再进入正式发布。
