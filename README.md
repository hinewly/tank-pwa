# tank-pwa · 坦克对战：钢铁代差

DaoBox 正式娱乐子程序。首版采用 99A 炮塔/车长第一人称视角的三关递进战役：第 1 关「前哨接触」为 5 辆虎式和 6 处稀疏掩体，第 2 关「装甲推进」为 8 辆虎式和 19 处工事，第 3 关「十面合围」为 10 辆虎式和完整 37 处战场工事。敌方车体完全静止，只有炮塔限速转动；双方主炮都是单发装填、一炮一炮射击，不能按住连发。炮弹会被混凝土路障、叠袋墙、原木结构、土堆、敌车和坦克残骸真实阻挡。

战场远景、六款坦克、炮塔内部与掩体使用 Vidu 原创素材；有效交战距离按 `0–1500m` 计算。敌方 billboard 使用落地阴影、接触压暗、距离大气衰减和下沉 6% 的底边处理，避免像贴纸一样漂浮。左上战术雷达以炮塔朝向为上方，持续显示玩家车体/炮塔方向、本关敌军与主要掩体。菜单中的“车型图鉴”可查看六款坦克并切换四种战场远景。

```bash
cd /Users/zoujiean/CodeX/tank-pwa
node tools/static-server.cjs
```

打开 `http://127.0.0.1:8811/tank/`。该工具会按正式路径 `/tank/` 提供 `public/`，便于验证 Service Worker scope。本地没有 DaoBox 门户时，游戏会自动以游客本地模式运行；联网正式环境会异步注入账号胶囊、共享时长、打卡与反馈入口。

```bash

```

## 操作

- PC：`W` 前进、`S` 倒车、`A/D` 车体左转/右转、`Q/E` 左右横移；鼠标锁定后 360° 环视，按住右键进入约 3.2× 炮长镜，左键或 `Space` 点按单发开火，`R` 装填，`Esc` 暂停。暂停菜单可直接“重新开始本关”。
- 手机：横屏优先；左摇杆驾驶，右摇杆环视/瞄准，独立瞄准键切换炮长镜，独立开火键点按单发。

宽视野固定为 `1×`；炮长镜约 `3.2×`。99A 自动装填 `0.8s`，虎式每发装填 `5.2s`；按住开火不会自动续射。默认采用新手难度：99A 装甲 180、虎式单发炮击基础伤害 10，虎式首轮错峰并带明显散布，玩家可以在弹丸飞行期间横向机动躲避。开镜不停止移动、不改变炮塔世界角，也不提供自动锁敌或距离伤害衰减。

木障、沙袋和土堆不再一炮即毁，分别约承受 4、6、8 发 99A 主炮；每次命中显示实际伤害，并逐步出现裂纹、掉袋或坍塌。混凝土和残骸永久阻挡。炮弹被掩体挡住时，准星下方会显示掩体类型和预计剩余炮数。虎式首次非致命受击会起火，再命中摧毁后留下持续冒烟的烧毁残骸。

发动机使用 CC BY 3.0 重型车辆循环采样，音量、音高与低通滤波随油门、速度和转向变化；我方/敌方主炮使用 CC0 炮声采样，并与 CC BY 3.0 爆炸尾音叠加；装甲命中使用 CC0 金属撞击采样，近失掠弹和装填声使用 WebAudio 实时合成。素材来源见 `public/assets/audio/README.md`，页面底部保留授权署名。

本作是 2.5D 全景投影，鼠标和手机右摇杆支持左右环视与约 `±7°` 俯仰。背景地平线、坦克接地和炮弹高度共用同一 pitch：抬高炮口会飞越目标，压低可打地面或低掩体，不会只移动远景导致坦克悬空。炮弹是无重力平直弹道，弹体朝向按前后两帧屏幕轨迹旋转。

坦克和掩体统一使用投影地面接点：贴图底部按屏幕高度下沉，接触阴影按真实绘制宽度生成，并在底边叠加土地色渐变，避免透明边缘或尺寸不一致造成悬浮。所有掩体单发命中后显示实际伤害和破损阶段。

正式掩体、远景、坦克和炮塔内部均为本地 WebP 素材。`public/data.js` 的 `COVER_ART`、`TANK_ART`、`BACKDROPS`、`COCKPIT_ART` 是资源入口；图片加载失败时才回退到 Canvas 矢量，替换素材不会改变碰撞、耐久、射程或固定炮台逻辑。炮塔内部遮罩位于世界场景之上、HUD/准星/伤害数字之下，规格见 `public/assets/covers/README.md` 与 `public/assets/cockpit/README.md`。

## 技术约束

纯 Vanilla JS + Canvas 2D，无框架、无构建、无 npm 运行依赖。`public/` 可直接作为静态站部署。
