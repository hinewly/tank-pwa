# tank-pwa · 坦克对战：钢铁代差

DaoBox 正式娱乐子程序。当前采用 99A 炮塔/车长第一人称视角的 12 关、5 场景战役，覆盖欧洲废墟、稀疏森林、沙石荒漠、开阔平原和海岸沙丘。前 5 关默认德国虎式，第 6～8 关默认日本 97 式，第 9～11 关默认美国谢尔曼，第 12 关为虎式与谢尔曼混合合围；进入前也可统一覆盖为任一敌方阵营。敌方车体完全静止，只有炮塔限速转动；双方主炮都是单发装填，不能按住连发。炮弹会被混凝土路障、叠袋墙、原木结构、土堆、树木、敌车和坦克残骸真实阻挡。

战场远景、六款坦克、炮塔内部与掩体使用 Vidu 原创素材；玩家射程 `2200m`，敌军从 `1300m` 内才开始炮击。超过敌军射程的可见目标会显示红色车型与距离标签，适合用 3.2× 炮长镜远距点名。世界与驾驶舱分离震动，近地物体有独立视差和速度线，减少移动漂浮感。左上战术雷达以炮塔朝向为上方，持续显示玩家车体/炮塔方向、本关敌军与主要掩体。菜单中的“车型图鉴”可查看六款坦克并切换五种战场远景。

```bash

```

打开 `http://127.0.0.1:8811/tank/`。该工具会按正式路径 `/tank/` 提供 `public/`，便于验证 Service Worker scope。本地没有 DaoBox 门户时，游戏会自动以游客本地模式运行；联网正式环境会异步注入账号胶囊、共享时长、打卡与反馈入口。

## 操作

- PC：`W` 前进、`S` 后退、`Shift` 加速、`A/D` 车体左转/右转、`Q/E` 左右横移；鼠标锁定后 360° 环视，按住右键进入约 3.2× 炮长镜，左键或 `Space` 点按单发开火，`R` 装填，`Esc` 暂停。暂停菜单可直接“重新开始本关”。
- 手机：横屏优先；左摇杆上下控制前进/后退、左右控制转向，推到底自动加速；独立左移/右移按钮负责横移；右摇杆环视/瞄准，独立开火和瞄准键控制射击与炮长镜。

宽视野固定为 `1×`；炮长镜约 `3.2×`。99A 自动装填 `0.8s`；日本 97 式、谢尔曼和虎式按各自装填周期独立射击，按住开火不会自动续射。日本 97 式耐久 48，通常一炮击毁；谢尔曼与虎式耐久 104，正面通常两炮。开镜不停止移动、不改变炮塔世界角，也不提供自动锁敌或距离伤害衰减。

双方火力不对等：99A 主炮一炮可摧毁木障、沙袋和土堆，混凝土最多两炮；虎炮打同样工事需要约 8～16 炮。每次命中显示实际伤害，并出现裂纹、掉袋或坍塌。坦克残骸为永久实体，再中炮只显示“残骸挡住炮弹”，不会消失。虎式首次非致命受击会起火，再命中摧毁后留下持续冒烟的烧毁残骸。

发动机使用 CC BY 3.0 重型车辆循环采样，音量、音高与低通滤波随油门、速度和转向变化；我方/敌方主炮使用 CC0 炮声采样，并与 CC BY 3.0 爆炸尾音叠加；装甲命中使用 CC0 金属撞击采样，近失掠弹和装填声使用 WebAudio 实时合成。素材来源见 `public/assets/audio/README.md`，页面底部保留授权署名。

主炮炮击与跳弹当前使用用户于 2026-11-28 指定采用的影视裁切音效，分别对应 `tank-cannon.mp3` 和 `tank-ricochet.mp3`；源区间与处理方式见 `public/assets/audio/README.md`。尚未采用的候选音效仍放在 gitignore 的 `public/assets/audio/local/`。

本作是 2.5D 全景投影，鼠标和手机右摇杆支持左右环视与约 `±22°` 俯仰。炮弹从炮口高度出膛，压低准星可以打到沙袋、混凝土和土堆；背景地平线、坦克接地和炮弹高度共用同一 pitch。炮弹是无重力平直弹道，弹体朝向按前后两帧屏幕轨迹旋转。

坦克和掩体统一使用投影地面接点：贴图底部按屏幕高度下沉，接触阴影按真实绘制宽度生成，并在底边叠加土地色渐变，避免透明边缘或尺寸不一致造成悬浮。所有掩体单发命中后显示实际伤害和破损阶段。

正式掩体、远景、坦克和炮塔内部均为本地 WebP 素材。`public/data.js` 的 `COVER_ART`、`TANK_ART`、`BACKDROPS`、`COCKPIT_ART` 是资源入口；图片加载失败时才回退到 Canvas 矢量，替换素材不会改变碰撞、耐久、射程或固定炮台逻辑。炮塔内部遮罩位于世界场景之上、HUD/准星/伤害数字之下，规格见 `public/assets/covers/README.md` 与 `public/assets/cockpit/README.md`。

## 技术约束

纯 Vanilla JS + Canvas 2D，无框架、无构建、无 npm 运行依赖。`public/` 可直接作为静态站部署。
