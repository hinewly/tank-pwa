## 后处理

运行：

```bash
python3 tools/process-vidu-assets.py
```

流程：

1. 检查 WebP RIFF 头并修正错误扩展名。
2. 用白底连通域生成透明 Alpha。
3. 坦克图按三个主体连通域切出 `front/side/rear`。
4. 掩体图集按对象间隔切出单件。
5. 去除邻近物件碎屑、羽化边缘。
6. 炮塔内部按纯绿键控生成 Alpha，以 5×5 高斯核羽化 1.05；去绿时将绿色通道限制为 `max(red, blue) × 1.08`，避免绿边。
7. 限制最长边并压缩为 WebP；炮塔内部质量为 90。
8. 生成 `public/assets/manifest.json`，记录尺寸、字节数、SHA-256 与源文件。

最终生成 34 个运行时素材，当前总计 `1,545,340 bytes`（约 `1.47 MiB`），比上一版增加 `121,156 bytes`。
